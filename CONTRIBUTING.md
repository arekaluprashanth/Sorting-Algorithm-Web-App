# Contributing to SortBench

Thank you for considering contributing to SortBench!

## Guidelines

1. **Fork & Clone**: Create a fork of the repository and clone it locally.
2. **Branching**: Create a feature branch off `main` (e.g. `feat/new-algorithm` or `fix/worker-latency`).
3. **Quality Standards**:
   - Ensure all code passes `npm run lint`.
   - Ensure all unit tests pass `npm test`.
   - Ensure `npm run build` succeeds without TypeScript compilation errors.
4. **Pull Requests**: Submit a PR targeting `main` using the provided Pull Request template.
