# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0-RC] - 2026-07-31

### Added
- **Web Worker Engine**: Asynchronous non-blocking benchmark engine.
- **Queue Manager**: Multi-job queue management with pause, cancel, reorder, and retry capabilities.
- **Analytics Dashboard**: Interactive execution time and operations comparison charts.
- **Learning Center**: Step-by-step sorting visualizer powered by `framer-motion` and pseudocode panel.
- **Reporting & Export Suite**: CSV, JSON, PDF with chart image snapshots, and printable HTML reports.
- **Testing Infrastructure**: Comprehensive Vitest suite with 100+ tests and coverage reports.
- **PWA & Offline Shell**: Web app manifest, service worker offline shell, and Open Graph SEO meta tags.
